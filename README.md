# 老鼠图片库 使用说明

## 项目结构

```
老鼠图片/
├── images/          图片和视频文件
├── tagtree.txt      标签层级定义
├── tags.txt         图片/视频标签（由 tagger.html 导出）
├── tagger.html      浏览器端标签编辑工具
├── build.py         生成网页的脚本
├── check.py         检查 images/ 里被跳过的文件
└── index.html       生成的网页
```

## 使用步骤

1. 将图片和视频放入 `images/` 文件夹。支持的图片格式：`.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.bmp`、`.jfif`、`.avif`。支持的视频格式：`.mp4`、`.webm`、`.mov`、`.mkv`、`.avi`、`.m4v`。

2. 新建 `tagtree.txt`，填入标签的父子关系。每行一条路径，用 `/` 分隔父标签与子标签，例如：

   ```
   摄影/特写
   摄影/远景
   宠物/仓鼠
   ```

   这表示“特写”和“远景”属于“摄影”，“仓鼠”属于“宠物”。

3. 用浏览器打开 `tagger.html`：
   - 选择 `images` 文件夹。图片和视频都会加载进来。
   - 选择 `tagtree.txt`。
   - （可选）如果之前已经导出过 `tags.txt`，选择它继续编辑。
   - 点击“开始编辑”。
   - 使用“上一张 / 下一张”按钮或键盘左右方向键切换项目。
   - 图片直接显示；视频显示为可播放的播放器（带控制条，可预览）。
   - 点击标签按钮来选中或取消标签。
   - 在备注输入框中填写备注（可选）。
   - 点击“导出 tags.txt”，浏览器将下载该文件。将下载的 `tags.txt` 放入项目根目录。

4. 在项目根目录运行：

   ```
   python build.py
   ```

   脚本会读取 `tags.txt`、`tagtree.txt` 和 `images/`，生成 `index.html`。

5. 打开 `index.html` 浏览图片和视频。页面顶部有搜索框和标签按钮，点击缩略图可查看大图或播放视频。

## 检查遗漏的文件

如果发现网页上显示的条目数比 `images/` 里实际的文件少，运行：

```
python check.py
```

它会列出 `images/` 里所有**不会被 `build.py` 收录**的文件（比如表格、压缩包、不支持的格式），并给出原因。根据输出决定是删掉、转格式，还是把扩展名加进 `build.py`。

## 标签层级（tagtree.txt）

每行一条路径，`/` 分隔父标签与子标签。`#` 开头的行是注释。

子标签会自动归属到父标签。例如给图片打上“特写”，它也会获得“摄影”标签。

## 图片/视频标签（tags.txt）

格式为：

```
文件名 | 标签1,标签2 | 备注
```

- 标签用英文逗号分隔。
- 备注可省略。
- `#` 开头的行是注释。

示例：

```
001.jpg | 特写,黑白 | 趴在我手上
002.mp4 | 仓鼠 | 
003.jpg | 远景 | 
```

`tagger.html` 导出的文件符合此格式，可直接用于 `build.py`。

## 修改标签

使用 `tagger.html` 加载现有的 `tags.txt` 进行修改：

1. 打开 `tagger.html`，选择 `images` 文件夹。
2. 选择 `tagtree.txt`。
3. 在“加载已有的 tags.txt 继续编辑”处选择现有的 `tags.txt`。
4. 点击“开始编辑”，修改标签或备注。
5. 再次点击“导出 tags.txt”，覆盖原文件。
6. 重新运行 `python build.py`。

## 查找与筛选

在 `index.html` 中：

- **搜索框**：输入关键词，匹配文件名、标签、备注。空格分隔多个关键词，图片/视频需同时满足所有关键词。
- **标签按钮**：点击标签可选中（变黑），再次点击取消。可以同时选中多个标签，只显示同时具有所有选中标签的图片/视频。
- **图片下方的标签**：点击可快速将对应标签加入筛选。
- **分页**：页面底部有翻页按钮，每页显示 40 个（可在 `build.py` 中修改 `PER_PAGE`）。

## 重新生成

修改 `tags.txt` 或 `tagtree.txt`，或增删 `images/` 中的文件后，再次运行：

```
python build.py
```

`index.html` 会被覆盖更新。

## 常见问题

**图片或视频不显示、数量不全**  
运行 `python check.py` 看是哪些文件被跳过了。

**文件名中包含特殊字符**  
文件名含空格、`#`、`%` 等字符时，浏览器可能无法正确加载。建议将文件重命名为仅包含字母、数字、下划线、连字符的名称。

**每页显示数量**  
修改 `build.py` 中的 `PER_PAGE` 变量，默认值为 `40`。

**中文乱码**  
所有文本文件（`tagtree.txt`、`tags.txt`）应保存为 UTF-8 编码。

**页面样式**  
`build.py` 中的 `TEMPLATE` 字符串包含全部 HTML 和 CSS。如需修改样式，直接编辑该字符串中的 `<style>` 部分。
