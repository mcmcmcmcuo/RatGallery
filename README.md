# 老鼠图片库

本地老鼠图片和视频管理工具。用浏览器给文件打标签、加备注、修改时间，支持搜索、多标签筛选、层级标签、批量编辑、大图预览和视频播放。所有数据保存在本地，不会上传网络。

## 项目结构

```
老鼠图片库/
├── images/          图片和视频文件
├── data.json        标签、备注、时间数据（自动生成）
├── server.py        本地服务器
├── index.html       页面结构
├── style.css        样式
├── app.js           前端逻辑
└── 启动.bat         双击启动（可选）
```

## 环境要求

- Python 3
- 浏览器（Chrome、Edge 或 Firefox）
- Pillow（可选，安装后可读取照片的拍摄时间）

安装 Pillow：

```
pip install Pillow
```

## 使用步骤

1. 将图片和视频放入 `images/` 文件夹。

   支持的图片格式：`.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.bmp`、`.jfif`、`.avif`

   支持的视频格式：`.mp4`、`.webm`、`.mov`、`.mkv`、`.avi`、`.m4v`

2. 启动服务器：

   ```
   python server.py
   ```

   在 Windows 下也可以双击 `启动.bat`。

3. 浏览器打开 `http://localhost:8000`。

4. 使用完毕后按 `Ctrl+C` 停止服务器。

## 启动.bat（可选）

在项目文件夹中新建文本文件，命名为 `启动.bat`，内容如下：

```bat
@echo off
cd /d "%~dp0"
start "" http://localhost:8000
python server.py
pause
```

保存后双击即可启动。

## 功能说明

### 标签层级

在顶部展开「标签层级」，每行写一条路径，用 `/` 分隔父子关系：

```
摄影/特写
摄影/远景
宠物/仓鼠
宠物/小白鼠
```

保存后，给图片打上「特写」，它会自动继承「摄影」标签。点击顶部的「摄影」按钮，会筛选出所有带「摄影」或任意子标签的图片。

### 编辑标签

点击任意图片的「编辑」，弹出编辑框：

- **标签**：可以点击下方候选标签按钮添加或取消，也可以手动输入，逗号分隔。
- **备注**：填写说明文字。
- **时间**：默认读取照片的拍摄时间；读不到的用文件修改时间。可以手动修改。

点击「保存」后写入 `data.json`。

### 搜索与筛选

- **搜索框**：匹配文件名、标签、备注。空格分隔多个关键词，需全部命中。
- **标签按钮**：点击选中（黑色），再次点击取消。可以同时选择多个，只显示同时具有所有选中标签的图片。
- **清空筛选**：一键恢复全部显示。

### 排序

顶部下拉菜单，支持以下排序方式：

- 时间 新 → 旧
- 时间 旧 → 新
- 文件名 A → Z
- 文件名 Z → A

### 批量编辑

点击顶部「批量编辑」，进入批量模式：

1. 点击图片切换选中状态（左上角出现勾选标记）。
2. 底部工具栏显示已选数量。
3. 点击「＋ 加标签」或「－ 去标签」，选择要操作的标签，立即应用到所有选中图片。
4. 「全选本页」选中当前页所有图片。
5. 「清空选择」取消所有选中。
6. 「退出批量」回到普通模式。

### 查看大图与播放视频

点击缩略图打开大图或视频播放器。按 `Esc` 或点击空白处关闭。

### 分页

每页显示 40 项，可在 `app.js` 顶部修改 `PER_PAGE` 常量调整。

## 数据文件

`data.json` 保存所有标签数据，结构如下：

```json
{
  "_tree": "摄影/特写\n摄影/远景\n",
  "001.jpg": {
    "tags": ["特写", "黑白"],
    "note": "趴在我手上",
    "time": 1609459200
  }
}
```

- `_tree`：标签层级定义，对应顶部文本框的内容。
- 每个文件名对应一个对象，存储标签、备注、时间。
- `time` 是 Unix 时间戳（单位：秒）。

备份时直接复制整个项目文件夹即可。`data.json` 也可以单独备份。

## 添加新文件

将新的图片或视频放入 `images/` 文件夹，然后刷新浏览器页面（`F5`）。已有的标签数据不会丢失。

## 常见问题

**图片或视频不显示**

- 检查文件扩展名是否在支持列表里。
- 检查 `images/` 文件夹是否存在。
- 检查 `server.py` 是否正在运行。

**时间全部显示为今天**

复制文件会改变文件的创建时间。如果照片有 EXIF 拍摄时间，安装 Pillow 后会自动读取。已经变化的时间，进入「编辑」手动修改一次即可固定。

**标签没有继承父标签**

检查 `tagtree.txt` 或顶部「标签层级」中的标签名，需要与实际填写的标签完全一致。

**修改样式**

编辑 `style.css`。

**修改前端逻辑**

编辑 `app.js`。

**修改服务器行为**

编辑 `server.py`，修改后需要重启服务器。

**修改端口**

编辑 `server.py` 中的 `PORT = 8000`，改成其他数字。

## 注意事项

- 服务器只绑定 `127.0.0.1`，只能本机访问。
- 图片和视频不会上传到任何地方。
- 所有数据都保存在本地文件夹中。
